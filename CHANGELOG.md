## [1.0.0] - 2026-11-02

### Added

- Player-requested Rock the Vote flow with configurable request ratio, minimum players, cooldowns and vote duration.
- Random map ballots rendered through the shared `sws2-cs2menus` menu service.
- Map changes delegated to `sws2-cs2mapmanager`, including Workshop download progress.
- Disconnect, vote-timeout and map-unload lifecycle cleanup.
- Hot-reloadable configuration and English/Simplified Chinese translations.
- Build, CI and main-branch release workflows.
